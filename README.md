# 🛡️ Phishing Detection and Response System (PDRS)

An ML-based Phishing Detection and Response System designed to identify phishing threats using Machine Learning and provide a secure platform for managing suspicious emails.

## 📌 Project Overview

The Phishing Detection and Response System (PDRS) uses Natural Language Processing and Machine Learning techniques to classify URLs or email-related text as phishing or legitimate.

The system integrates a FastAPI backend, React frontend, and PostgreSQL database to provide a platform for phishing detection and response management.

## ✨ Key Features

- **Phishing Detection:** Detects potential phishing threats using a trained Machine Learning model.
- **ML Classification:** Uses TF-IDF feature extraction and an XGBoost classifier.
- **Dashboard:** Displays phishing detection information.
- **Scan History:** Maintains records of previous scans.
- **Email Quarantine:** Provides a feature to manage suspicious emails.
- **Secure Authentication:** Supports secure user authentication.
- **Admin Module:** Provides administrative functionality.
